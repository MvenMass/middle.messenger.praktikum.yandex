# Messenger

Учебный проект для курса Яндекс Практикума. Делаю свой мессенджер, похожий по идее на телеграм.

Сейчас закончил первый спринт: сверстал все нужные экраны и настроил сборку. Формы пока просто для вида, данные никуда не уходят — это добавлю позже.

## Как запустить

Нужен Node.js 22 или новее.

Сначала ставим зависимости:

```bash
npm install
```

Потом можно запускать:

- `npm run dev` — для разработки, сайт откроется на http://localhost:3000
- `npm run build` — собрать проект в папку dist
- `npm run start` — собрать и запустить уже готовую версию, тоже на порту 3000

## Какие страницы есть

- `/` — вход
- `/sign-up` — регистрация
- `/messenger` — список чатов и переписка
- `/settings` — настройки профиля
- `/500` — ошибка сервера
- любой другой адрес — 404

Переход между страницами пока через обычные ссылки.

## Что использовал

TypeScript, Vite, Handlebars для шаблонов, Sass и БЭМ для стилей.

## Где что лежит

```
src/
  components/  — кнопки, поля ввода, ссылки, аватар, иконки
  pages/       — сами страницы и фейковые данные для вёрстки
  styles/      — переменные, миксины, общие стили
  main.ts      — отсюда всё стартует, по адресу выбирается нужная страница
ui/            — картинки с макетами
```

Компоненты из handlebars подключаются сами. Беру имя из файла: icon-send.hbs в шаблоне вызывается как `{{> IconSend}}`.

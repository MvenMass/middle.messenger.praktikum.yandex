# Messenger

Учебный проект для курса Яндекс Практикума

Сейчас закончен второй спринт: страницы собраны из компонентов на базе своего класса `Block`, формы валидируются, а данные из них выводятся в консоль. Сервера пока нет

## Как запустить

Нужен Node.js 22 или новее.

```bash
npm install
```

- `npm run dev` - режим разработки на http://localhost:3000
- `npm run build` - проверка типов и сборка в папку dist
- `npm run start` - собрать и запустить готовую версию на порту 3000
- `npm run lint` - проверка типов (tsc), ESLint и Stylelint

## Страницы

- `/` - вход
- `/sign-up` - регистрация
- `/messenger` - список чатов и переписка
- `/settings` - настройки профиля
- `/500` - ошибка сервера
- любой другой адрес - 404

## Что сделано

- Базовый класс `Block` с жизненным циклом: `componentDidMount`, `componentDidUpdate` и перерисовкой при изменении props через `setProps`. Вложенные компоненты и списки компонентов передаются прямо в props.
- Компоненты: кнопка, ссылка, аватар, поле ввода, поле формы с ошибкой, форма, сообщение в чате.
- Валидация описана один раз в `services/validation.ts` и работает по `blur` и при отправке формы. Подключена к формам входа, регистрации, настроек профиля, смены пароля и отправки сообщения.
- При успешной отправке формы объект с полями выводится в консоль, страница не перезагружается.

## Архитектура

Проект разделён по MVC:

- **View** - компоненты и страницы, наследники `Block`, разметка в Handlebars-шаблонах.
- **Model** - сервисы с бизнес-логикой (валидация, сбор данных формы), типы данных и моковые данные.
- **Controller** - контроллеры принимают данные из форм и передают их дальше. Пока они пишут данные в консоль, в третьем спринте здесь появятся запросы к API.

```
src/
  core/         - Block и EventBus
  components/   - переиспользуемые компоненты, у каждого своя папка с index.ts
  pages/        - страницы, в pages/messenger/blocks - блоки, нужные только чату
  controllers/  - контроллеры
  services/     - валидация и сбор данных форм
  models/       - типы данных
  mocks/        - тестовые данные для чатов и профиля
  styles/       - переменные, миксины и общие стили
  main.ts       - точка входа, выбирает страницу по адресу
ui/             - картинки с макетами
```

Иконки - это обычные Handlebars-партиалы. Имя берётся из файла: `icon-send.hbs` в шаблоне вызывается как `{{> IconSend}}`.
